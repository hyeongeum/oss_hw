# Project A+

대학생의 한 학기를 2D 횡스크롤 액션 플랫폼 게임으로 표현한 오프라인 싱글 플레이 게임입니다. 강의실, 도서관, 팀플방, 시험장을 진행하며 졸음, 스마트폰, 과제, 팀플과 싸우고 중간고사와 기말고사 보스를 처치합니다.

## 실행 방법

- 권장 Unity 버전: `2022.3.62f3`
- 바로 실행: `outputs/ProjectAPlus_Windows/Project A+.exe`
- Unity 실행: `Assets/ProjectAPlus/Scenes/BootScene.unity`를 열고 Play
- 에셋 재생성: `Tools/Project A+/Generate All Assets`

## 조작법

| 입력 | 기능 |
|---|---|
| A / D, 방향키 | 이동 |
| Space / W / 위 방향키 | 점프, 길게 눌러 높은 점프 |
| S / 아래 방향키 | 일방통행 발판 내려가기 |
| J / 마우스 왼쪽 | 기본 공격 |
| 공중에서 S + J | 내려차기 |
| K / Left Shift | 회피 |
| Q / E | 아이템 사용 |
| Tab / I | 능력치 창 |
| Esc | 일시정지 |
| Enter | 컷신 진행 |

## 게임 흐름

타이틀 → 오프닝 → Stage 1~4 → 중간고사 → Stage 6~9 → 기말고사 → 엔딩 → 최종 성적

일반 방은 목표 처치 수와 출구 도달, 보스 방은 보스 처치가 클리어 조건입니다. 방 클리어 보상은 즉시 적용되며 별도 보상 뽑기는 없습니다. 전체 플레이 시간은 약 30분을 목표로 구성했습니다.

## 스탯

- `mental`: 현재 체력
- `maxMental`: 최대 멘탈
- `studyPower`: 기본 공격력
- `review`: 추가 피해와 치명타 보정
- `attackEfficiency`: 공격 간격 감소
- `movementEfficiency`: 이동, 점프, 회피 강화
- `growthPoint`: 능력치 투자 포인트
- `exp`, `level`, `score`: 성장 및 최종 성적 계산

`studyEfficiency` 스탯은 사용하지 않습니다.

## 스테이지

1. 첫 수업 - 튜토리얼
2. 강의 집중
3. 과제 폭탄
4. 팀플 지옥
5. 중간고사 감시자
6. 다시 시작되는 학기
7. 발표 공포
8. 레포트 마감
9. 기말 직전 밤샘
10. 기말고사 심판관

## 지형과 점프 규칙

- 메인 바닥은 끊기지 않으며 낙사 구간이 없습니다.
- 일반 스테이지는 서로 다른 구조의 전투 챔버 4개와 잠금 게이트를 순서대로 통과합니다.
- 각 챔버는 저층 전투면, 중층 우회로, 고층 보상 루트, 하강 지점을 조합합니다.
- 스테이지별로 `Fork`, `Crown`, `ZigZag`, `TwinDeck`, `Well`, `Cross` 구조를 다른 순서와 방향으로 배치합니다.
- 카메라는 현재 전투 챔버 중심에 고정되고 게이트를 통과할 때 다음 방으로 부드럽게 전환됩니다.
- 보스 스테이지는 중앙 전투 공간과 좌우 회피 루트가 분리된 전용 아레나를 사용합니다.
- 상단 발판은 아래에서 통과하고 위에서 착지하는 일방통행 발판입니다.
- 배경 건축물과 천장 장식에는 충돌 판정이 없습니다.
- 몬스터는 플레이어와 서로 막히지 않으며 접촉 히트박스로 피해를 줍니다.
- 필수 발판 최대 상승폭은 `1.45` 유닛이며 실제 기본 점프 검증 상승량은 `2.81` 유닛입니다.
- 자동 검증은 모든 정적 발판이 시작 바닥에서 도달 가능한지 검사합니다.

## 저장 위치

진행도, 스탯, 아이템, 설정은 `Application.persistentDataPath/project_aplus_save.json`에 자동 저장됩니다. 저장 시 `project_aplus_save.json.bak` 백업을 함께 관리하며, 기본 저장 파일이 손상되면 백업 또는 기본 데이터로 복구합니다.

스테이지 시작 상태는 재도전 체크포인트로 보관됩니다. 재도전 시 해당 방에서 획득한 임시 보상은 초기화되므로 보상을 중복 획득할 수 없습니다.

## 에셋

그래픽은 프로젝트 내부 `FreshPixelArt` 생성 코드와 포함된 PNG를 사용합니다. 런타임 플레이어, 적, 보스, 아이템, 이펙트, 지형, 배경, UI는 Point Filter와 정수 배율 렌더링을 사용합니다. 외부 서버나 온라인 에셋 다운로드 없이 실행됩니다.

사용자가 제공한 제작 시트는 `Assets/ProjectAPlus/ArtSource/ProvidedSheets`에 포함되어 있습니다. `Tools/Project A+/Generate All Assets` 실행 시 필요한 플레이어 모션, 적, 보스, 캠퍼스 지형과 소품만 추출하고 체크무늬 배경을 투명화한 뒤 `Assets/ProjectAPlus/Resources/ProvidedArt`에 고정 크기 스프라이트로 생성합니다. 생성된 리소스는 런타임 엔티티와 맵 타일에 직접 적용됩니다.

## 빌드 방법

1. Unity에서 프로젝트를 엽니다.
2. `Tools/Project A+/Build Windows Game`을 실행합니다.
3. `outputs/ProjectAPlus_Windows/Project A+.exe`를 실행합니다.

기본 해상도는 1920x1080이며 설정 화면에서 창 모드, 전체화면, 지원 해상도를 변경할 수 있습니다.

제출하거나 다른 PC로 옮길 때는 `Project A+.exe`만 복사하지 말고 `outputs/ProjectAPlus_Windows` 폴더 전체를 함께 복사해야 합니다.
